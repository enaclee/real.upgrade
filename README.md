# ENACLEE UPGRADE — демоверсия

Статический браузерный прототип апгрейдера с локальным инвентарём.

## Возможности
- Загрузка фото с телефона или компьютера.
- Сжатие изображений в браузере и сохранение в IndexedDB.
- Сохранение баланса и истории в localStorage.
- Выбор исходного предмета и цели, расчёт шанса, анимация результата.
- Демо-предметы для проверки интерфейса.

## Важно
- Это прототип, не готовый публичный сервис.
- Фото и загруженные предметы сохраняются только в браузере на текущем устройстве.
- Рыночная цена не распознаётся: стоимость задаётся вручную как игровая.
- Вырезание фона пока не подключено; фотографии сохраняются как есть. Следующий шаг — интегрировать локальную модель удаления фона.
- Результат апгрейда рассчитан на демо. Не использовать с реальными деньгами или ценными активами.
- В клиентском коде нет секретных ключей или настоящей авторизации.

## Локальный запуск
Открой `index.html` в браузере. Для наиболее надёжной работы IndexedDB и загрузки ресурсов рекомендуется запускать через локальный статический сервер.

## Публикация на GitHub Pages
1. Создай новый репозиторий на GitHub.
2. Загрузи `index.html`, `style.css`, `app.js`, папку `assets` и этот README.
3. В Settings → Pages выбери публикацию из ветки `main`, папка `/ (root)`.
4. Открой предоставленный GitHub Pages URL.
